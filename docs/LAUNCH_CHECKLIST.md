# 正式售卖前的验证清单

以下每一项都在真实环境里人工验证过，才算可以开卖。

## A. 后端

- [ ] `supabase db push` 三份迁移全部成功，`supabase db reset` 可重复重放
- [ ] `supabase functions deploy` 全部 11 个函数成功
- [ ] `supabase secrets list` 能看到 `CODE_LOOKUP_KEY`、`SESSION_TOKEN_KEY`
- [ ] 用 REST API（publishable key）直接查询任意业务表 → 空结果或权限错误
- [ ] 调用任意 `SECURITY DEFINER` 函数 → 权限错误

## B. 额度（最重要）

准备一个全新密码（额度 3）：

- [ ] 连续完成 3 轮测评，第 3 轮正常出结果
- [ ] 第 4 次输入密码 → 提示「次数已经用完」，且**没有**创建会话
- [ ] 第 3 轮结果页点「再测一次」→ 明确提示额度已用完
- [ ] 打开 8 个标签页同时用同一密码开始测评 → 成功创建的会话数恰好 ≤ 3
- [ ] 同一 `requestId` 重放 5 次 → 只扣 1 次额度，会话 id 相同
- [ ] 答题过程中刷新页面 / 切后台 / 改答案 → 额度不变
- [ ] 修改浏览器 localStorage 伪造 `remaining: 99` → 无效

## C. 业务闭环

- [ ] 正确密码 → 介绍页 → 24 题全部作答 → 出结果 → 保存长图 → 复制链接
- [ ] 未选答案时「下一题」为禁用态
- [ ] 返回上一题，原答案仍然勾选
- [ ] 改答案后重新提交，得分与报告随之改变
- [ ] 提交过程中重复点击不会创建两份结果
- [ ] 分享链接在**另一台设备**（无痕窗口 / 另一部手机）能打开同一份报告
- [ ] 分享链接被复制完整（末尾没有被截断）
- [ ] 「再测一次」后，**旧分享链接仍然指向旧结果**
- [ ] 「复制结果链接」与「再测一次」在同一行左右排列

## D. 长图导出

分别用 iOS Safari、Chrome Android、桌面 Chrome、Safari 桌面版验证：

- [ ] 长图内容完整，没有裁掉底部免责声明
- [ ] 中文字体清晰，没有方块字
- [ ] 文件名为 `人生选择指南-灯塔架构师.png`，不含密码
- [ ] iOS 优先出现系统分享面板（若不支持则出现预览图 + 长按提示）
- [ ] 桌面端直接下载 PNG
- [ ] 极长报告不会因为画布超限而失败（有降级逻辑）
- [ ] 导出失败时给出重试入口

## E. 部署

- [ ] GitHub Actions 绿灯，Pages 站点可访问
- [ ] 项目页的 `VITE_BASE_PATH` 正确，刷新不 404
- [ ] 直接打开 `https://<user>.github.io/<repo>/#/s/<token>` 能显示报告
- [ ] 部署到新路径后分享链接依然正确（改 `VITE_BASE_PATH` 重新构建验证）

## F. 移动端与可访问性

- [ ] 375px（iPhone SE）、390px、430px 无横向滚动
- [ ] 软键盘弹出时输入框不被遮挡
- [ ] 所有可点区域 ≥ 44px
- [ ] 系统开启「减弱动态效果」后页面不闪
- [ ] 屏幕阅读器能读出题目、进度、按钮状态

## G. 合规与文案

- [ ] 全站没有「心理诊断」「测出你的心理疾病」等表述
- [ ] 入口页、结果页、页脚、长图底部都有免责声明

## H. 数据与隐私

- [ ] 不收集姓名、手机号、身份证号、精确定位
- [ ] 只有必填的匿名会话数据 + 答题结果 + 报告
- [ ] 分享链接对外暴露的字段已复核
- [ ] 已准备好数据清理方式（例如过期分享链接定期删除）
